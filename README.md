# SPHealthcare – Hospital Management System

[![GitHub](https://img.shields.io/badge/GitHub-SPHealthcare-blue?logo=github)](https://github.com/yourusername/healthcare-hms)

## Overview
SPHealthcare is a **full-stack hospital management system** built with **MongoDB, Express.js, React.js, and Node.js (MERN stack)**. It provides separate dashboards for **doctors, admins, and patients** to manage healthcare operations efficiently.

## Live Demo
- **Patient/Frontend:** [🔗 SPHealthcare](https://sphealthcare.netlify.app/)  
- **Admin Dashboard:** [🔗 Dashboard](https://sphealthcare-dashboard.netlify.app/)

## Features
- **Role-Based Login:** Secure authentication for admins, doctors, and patients  
- **Admin Panel:** Add doctors, manage staff, and oversee hospital operations  
- **Patient Panel:** Book appointments, view profiles, and communicate with staff  
- **Doctor Panel:** Manage appointments and interact with patients  
- **Messaging System:** Built-in communication between users  
- **Efficient Data Handling:** CRUD operations handled smoothly with MongoDB backend  

## Tech Stack
- **Frontend:** React.js  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Tools:** VS Code, Git, GitHub, Postman  

## Challenges Faced
- Implementing **role-based authentication** for multiple user types  
- Managing data flow and **CRUD operations** efficiently in a full-stack environment  
- Designing **dynamic dashboards** for different roles  

## Future Scope
- Add **real-time notifications** for appointments and messages  
- Implement **analytics dashboards** for admin panel  
- Integrate with **payment gateways** for hospital billing
